# PetShop - "Šapa & Rep"

## O projektu
Ovaj projekat predstavlja savremenu web prodavnicu kućnih ljubimaca dizajniranu da korisnicima pruži intuitivno iskustvo pri pregledu i odabiru ljubimaca, hrane i opreme.
